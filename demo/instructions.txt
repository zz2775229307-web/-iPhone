# 录音示例（macOS）:
#   - 使用 QuickTime 或 Terminal 中的 `sox` / `rec` 命令录制，再导出为 mp3

常见问题：
- ImageMagick convert 报错：请检查 ImageMagick 版本或使用 rsvg-convert（librsvg）替代。
- ffmpeg 无法识别尺寸：检查 RESIZE 格式，或把 -vf "scale=..." 改为 -s 750x1334。
